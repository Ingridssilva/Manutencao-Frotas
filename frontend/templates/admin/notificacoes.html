Notificações automáticas

O sistema envia e-mails automaticamente para todos os usuários com perfil admin ou gestor. Você pode disparar manualmente abaixo ou aguardar o envio automático (configurado via scheduler).

CRLV vencendo
Alerta 30 dias antes do vencimento
CNH vencendo
Alerta 60 dias antes do vencimento
OS paradas
OS sem movimentação há mais de 7 dias
Pneus desgastados
Pneus com mais de 80% de vida consumida
Variável de ambiente necessária

Para os e-mails funcionarem, adicione no Render em Environment Variables:

EMAIL_REMETENTE=frota@empresaexemplo.com.br
EMAIL_NOTIFICACAO_FALLBACK=owner@empresaexemplo.com.br

O remetente precisa ser uma caixa de e-mail que o Azure AD tem permissão para enviar. O fallback é usado se nenhum gestor estiver cadastrado no sistema.
